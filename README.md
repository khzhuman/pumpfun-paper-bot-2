Driftline — a momentum paper-trading bot for pump.fun bonding curves. It buys small into new curves showing accelerating buy flow from many wallets, pyramids only into strength, and exits fast on a stop, trailing stop, fading flow, or old age.

## Run it

```sh
node main.ts
```
